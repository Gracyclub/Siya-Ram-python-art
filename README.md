# 🎨 Python Turtle Art Animation

An interactive Python application that turns image outlines and vector coordinates into smooth, dynamic turtle sketch animations.

---

## ⚡ Quick Start Guide

Run the following commands in your terminal to set up and start the animation:

# 1. Clone the repository
```
git clone https://github.com/Gracyclub/python-turtle-art.git
```

# 2. Open project directory
```
cd python-turtle-art
```

# 3. Create and activate virtual environment (Optional)
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# 4. Install dependencies
pip install opencv-python numpy

# 5. Run the script
python siyaram.py

---

## 🛠️ Tech Stack & Tools
- Language: Python 3.x
- Graphics: Turtle Graphics Library
- Computer Vision: OpenCV (cv2), NumPy

---

## 📁 Project Structure
- `main.py` - Core animation script
- `assets/` - Input vector outlines and reference images
- `README.md` - Documentation

---

## 💡 How It Works
1. Analyzes vector points and edge boundaries using OpenCV.
2. Directs the Python Turtle pen to draw along the detected contours in real time.
3. Renders the finished artwork stroke by stroke on the screen.
